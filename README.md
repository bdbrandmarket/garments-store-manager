# BD Brand Market — Garments Factory

Static GitHub Pages factory management system.

Files:
- index.html
- style.css
- app.js
- logo.jpg (your existing logo)

Features:
- Dashboard
- Employees: add / edit / delete / search
- Daily attendance
- Monthly salary report
- Store / stock with stock in/out and low-stock alert
- Reports
- JSON backup / restore
- Responsive mobile layout
- UI animations

Data is stored in the browser using LocalStorage.
