# BD Brand Market — Garments Store Manager

Frontend V1 for the factory management website.

## Modules
- Dashboard
- Employees
- Daily Attendance
- Salary Report
- Store / Stock
- Stock In / Stock Out
- Stock movement history
- Reports placeholder

## Current stage
Static frontend V1. Browser LocalStorage is used temporarily for testing.

## Next stage
Connect Supabase PostgreSQL, authentication, Row Level Security, private employee document storage, cloud sync and Excel/PDF reports.

## GitHub Pages
Upload these files to the `garments-store-manager` repository. Then open Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
