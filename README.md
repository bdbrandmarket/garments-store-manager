# BD Brand Market — Attendance Web

এই version-এ শুধু Attendance রাখা হয়েছে।

## আছে
- Operator / Helper আলাদা section
- Present / Absent marking
- আজকের মোট কর্মী, Present, Absent ও percentage
- Date অনুযায়ী attendance LocalStorage-এ save
- Name / Card No search
- সব Present / সব Absent
- Print / Save as PDF
- Mobile responsive
- কোনো external CDN/dependency নেই

## GitHub Pages
Repository root-এ `index.html`, `style.css`, `app.js` রাখুন।
Settings → Pages → Deploy from branch → main → /(root) → Save.

নোট: বর্তমান ছবির 34টি Operator row sample হিসেবে দেওয়া হয়েছে। Helper list এখন খালি রাখা হয়েছে; Helper-এর নাম/ID দিলে app.js-এ সহজে যোগ করা যাবে।
